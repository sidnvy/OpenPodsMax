# Contributing

Keep changes focused and run the offline JVM and Python checks in README.md. Build from a clean checkout without private assets. Do not add credentials, unreviewed phone captures, device-specific addresses, proprietary assets or signing material. Update notices when incorporating third-party code. GPLv3 contributions must retain upstream attribution.

A hardware PASS requires device readback; a successful write or UI animation alone is insufficient. Clearly separate automated, human and untested results. Preserve paired devices and original settings during testing. Prefer deterministic regression tests over repeated manual exploration.

Documentation screenshots must be visually reviewed for personal information and excluded artwork before publishing. The public-tree check permits only the exact reviewed image hashes; replacing a capture requires a new review.
